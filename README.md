# Vanilla Node.js API

This is a **vanilla Node.js API** learning project. The goal is to understand the fundamentals of creating APIs using just Node.js without any frameworks.

---

## Project Goals

- Build a basic REST API using Node.js core modules
- Handle routing, requests, and responses manually
- Understand the inner workings of servers without Express or other libraries

---

## Notes

This project is for educational purposes and learning. 
The project is based on concepts demonstrated by [Traversy Media](https://github.com/bradtraversy/vanilla-node-rest-api), with my own understanding and adjustments.
